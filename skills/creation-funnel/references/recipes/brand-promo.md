# Brand Promo Recipe

Start from the creative charter and scene/shot contracts: audience perception,
brand assets, color/lighting commitments, pacing and final brand state. Validate
the whole rhythm with the existing animatic rather than treating a handoff as a
new renderer.

Authoring profiles may compile only those commitments. Use `portable_video` for
a provider-neutral transfer and the H3 profile only for its strict dialect.
Keep logo and identity ownership explicit in references, preserve visible text
verbatim, and separate each creative experiment. A returned file is manual
candidate media, never automatic proof of brand approval, generator identity
or Picture Lock. A human selects a take only after the existing review and QC
flow.
