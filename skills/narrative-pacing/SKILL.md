# 叙事节奏 · 钩子工艺(narrative-pacing)

留存是短视频**最大的一根杠杆**,而它几乎全押在头 3 秒。你的活:把下面的硬数字变成钩子、变成节拍、变成 `shots/*.yaml` 里的时长与顺序。引擎不编故事——节奏是你带进来的。

## 决策树:先判形态,再选钩子

- **竖屏短剧/情感/悬疑(1–3 分钟)** → 头 3 秒必须「信息前置 + 爆点前置」:先抛冲突/反转的结果,再倒叙。每集结尾留**钩子**(3 秒内让人停不下来)。用「反转/制造焦虑/悬念」原型。
- **竖屏知识/带货(15–60 秒)** → 头 3 秒用「痛点/利益前置/数字冲击」:先说「你亏在哪」或「3 个动作」。结构压到 Hook→Value→CTA,砍掉 Payoff 铺垫。
- **横屏知识/教程(1–3 分钟+)** → 3 秒钩子可稍缓,但**头 15 秒必须给出「看完你会得到什么」**;用「好奇/价值展示/避坑」。~25–35 秒处安排一次 pattern interrupt(换角度/换音乐/上花字)防漂移。
- **横屏短剧(7–12 分钟)** → 黄金三集/开场同理但节奏可呼吸;仍要每 2–3 分钟一个小高潮,详见 `series-breakdown`。

判断依据(硬数字):**头 3 秒留存 70–85% → 约 2.2× 播放;>65% → 4–7× 曝光;<60% → 几乎不进流量池**。完播随时长断崖下滑:**<15s→92%,16–30s→84%,31–60s→68%,1–3min→42%**。平台完播基线:Shorts~73%、TikTok~78%、Reels~65%。2025 爆款里 **84.3% 在 3 秒内用了钩子**。

## 结构骨架(照这个排节拍)

**Hook(0–3s)→ Value drop(4–15s)→ Payoff(16–45s)→ CTA(最后 5s)**。规矩:
- 最意外的一击**留到最后**(payoff/反转别提前泄光)。
- **每 2–3 秒一个 pattern interrupt**:换镜、换景别、SFX、花字、语气反转——任何一个「重置注意力」的动作。
- 在 **25–35 秒**这个漂移点,故意安排一次角度/音乐/节奏的 reset。
- 「一个利落的 20 秒 > 一个拖沓的 45 秒」——宁短勿拖。

## 10 种可编码钩子原型(选一个,别裸开场)

好奇 · 痛点 · 制造焦虑 · 价值展示 · 利益前置 · 数字冲击 · 避坑 · 权威 · 内幕 · 反转。四种加持手法:**信息前置 · 爆点前置 · 悬念 · 视觉冲击**。

**必须禁掉的开场**:「大家好我是…」自我介绍;过曝美颜大头怼脸;空洞的「震惊!/美炸了!」无信息惊叹。看到 `shots` 首镜是这类,直接重写。

## BEFORE / AFTER(业余 → 专业,附 WHY)

**例 1 — 开场自我介绍(致命)**
- BEFORE:`S001 dialogue: "大家好,我是小林,今天给大家分享一个理财故事。"`
- AFTER:`S001 dialogue: "我把三年工资全亏光的那天,他只说了一句话。"`(悬念 + 爆点前置)
- WHY:前者头 3 秒零信息,直接掉出流量池(<60%);后者抛「结果 + 未解之谜」,逼观众看下去。

**例 2 — 知识类埋没价值**
- BEFORE:`S001 action: 主播坐下,缓慢寒暄;第 12 秒才进正题。`
- AFTER:`S001 action: 开口即「90% 的人第一步就做错」;数字 + 痛点前置,正题 0 秒开始。`
- WHY:头 15 秒定生死;把「看完得到什么」提到最前(数字冲击 +「避坑」原型)。

**例 3 — 结尾泄了底 / 没钩子**
- BEFORE:末镜 `dialogue: "所以大家一定要理性消费,谢谢观看。"`
- AFTER:末镜 `dialogue: "而那张卡的最后一笔消费,是三天后——"` 画面切黑。
- WHY:短剧留存靠头尾;结尾抛新悬念(cliffhanger)拉复访/追更,说教式收尾等于放走观众。

**例 4 — 节奏拖沓(单镜过长)**
- BEFORE:`S003 duration: 9s` 单镜一镜到底讲完一段。
- AFTER:拆成 `S003 4s + S003b 3s`,中间换景别 + 一句反问(pattern interrupt)。
- WHY:>5 秒不换,注意力衰减;拆分 + 打断把 25–35 秒漂移点前的流失压住。

## 拷贝进工作笔记的清单(逐条打勾)

```
叙事节奏自检 · 复制到你的回复里逐条勾
[ ] 首镜 0–3s 用了 10 原型之一?(写出是哪个:好奇/痛点/反转/…)
[ ] 头 3 秒有「信息前置 或 爆点前置」,不是自我介绍/空惊叹/怼脸?
[ ] 结构走 Hook→Value→Payoff→CTA,最意外一击留到最后?
[ ] 每 2–3s 有一次 pattern interrupt(换镜/SFX/花字/语气)?
[ ] 25–35s 处有一次刻意 reset?
[ ] 总时长匹配完播预期(<15s≈92% … 1–3min≈42%),没有拖沓单镜(>5s 逐一复核)?
[ ] 末镜是钩子/悬念/反转,不是说教收尾?
[ ] (短剧)每集结尾一个钩子,3 秒内抓人?
```

## 失败目录(smells + 在 Manju 里长什么样)

| 症状 | 在 Manju 的表现 / 抓法 |
| --- | --- |
| 首镜自我介绍/空惊叹 | 首镜 `dialogue.text`/`action.main` 平淡;走工作流 E 首末镜复查改写 |
| 单镜过长、节奏拖 | `manju build --dry-run` / `manju status` 看每镜时长;>5s 单镜逐一审,`shots.duration` 拆分或改 `timeline/rules.yaml` 的 `max_shot_ms` |
| 全片一个景别、无打断 | `manju appearances` + `shot-design`:景别无变化 → pattern interrupt 缺失 |
| 结尾泄底/无钩子 | 末镜 `dialogue`;工作流 E 结尾悬念强化 |
| 想改的台词已锁 | 走 `proposals/`(工作流 F),永不 `unlock` |

## Manju 落地(把节奏钉进真相文本)

- **每镜时长**:`shots/SNNN.yaml` 的 `duration`(`auto`=对白时长+padding,或写死秒数);全局时序在 `timeline/rules.yaml` 的 `timing`(`min_shot_ms`/`max_shot_ms`/`default_shot_ms`)。
- **顺序/节拍**:`shots/index.yaml` 的 `order`;改序把理由写进 `manju propose`(工作流 D)。
- **首末镜仪式**:每轮 `manju build` 前后各做一次首末镜复查(核心手册工作流 E)。
- **看时长全貌**:`manju build --dry-run` 或 `manju status` 列出每镜与总时长。
- **改台词会让配音 stale**:`manju voice S002` 只增新 voice_take,build 不擅自重做(§7)。
- 与 `shot-design`(景别打断)、`cover-and-title`(标题/CTA 的钩子同源)配合使用。

## 验收 eval(自检这个技能有没有起作用)

1. 给一个平的三镜大纲,产出后首镜是否落在 10 原型之一、头 3 秒是否信息/爆点前置?
2. 给一个 45 秒单场景,是否被拆出 ≥3 个 pattern interrupt 且总时长匹配完播预期?
3. 给一个说教式末镜,是否被改写成 cliffhanger?
