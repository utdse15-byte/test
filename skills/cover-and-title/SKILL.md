# 封面标题(cover-and-title)

完播靠内容,点开靠封面标题。你的活:按平台选封面比例、用能闭合的好奇缺口写标题、避开会被判违规的绝对化词,并把封面钉到 packaging。

## 决策树:按平台选封面

- **YouTube / 横屏** → 16:9;**放脸**(+~35% CTR)、封面文案 **3–5 词**、700+ 加粗无衬线、占画面 ~20–30%、描边高对比;**极简封面**(+~18% CTR)胜过堆砌。好 CTR 约 5–7%。
- **小红书** → **3:4** 竖封面;三大驱动:**与我相关 / 对我有用 / 让我好奇**。
- **抖音/竖屏短剧** → 9:16;首帧即封面思维,脸 + 冲突瞬间;文案压到 3–5 词。

标题:**前 3–5 词前置关键词**;**数字 +20–30% CTR(奇数比偶数再高 ~20%)**;留一个「视频必须闭合」的好奇缺口;**中文疑问句 > 感叹句**;**禁绝对化 最/第一/唯一 与承诺性表述(监管)**。

## BEFORE / AFTER(业余 → 专业,附 WHY)

**例 1 — 封面无脸无文案**
- BEFORE:一张风景空镜当封面,无文字。
- AFTER:主角特写 + 3–5 词加粗文案(如「他为什么回来」),占 ~25% 画面、描边。
- WHY:脸 +35% CTR、极简文案 +18%;空镜无信息无情绪,点击率垫底。

**例 2 — 标题堆关键词在后**
- BEFORE:`一个关于理财和成长还有亲情的温暖短片分享`
- AFTER:`3 年亏光工资后 我才懂的一件事`(关键词/数字前置 + 好奇缺口)
- WHY:前 3–5 词决定停留;数字 +20–30%;缺口逼点击——但视频必须闭合它。

**例 3 — 绝对化 + 感叹**
- BEFORE:`全网第一!最强理财方法!震惊所有人!`
- AFTER:`这个方法 为什么没人早点告诉我?`(疑问句 + 去绝对化)
- WHY:最/第一/唯一 属违规高风险,平台可限流下架;疑问句在中文语境点击更好、也更合规。

**例 4 — 好奇缺口不闭合(标题党)**
- BEFORE:标题「结局你绝对想不到」,视频里根本没那个反转。
- AFTER:标题承诺的缺口在片中真的闭合(反转/答案兑现)。
- WHY:不闭合的好奇缺口拉高点击但砸完播与信任,算法反噬。

## 拷贝进工作笔记的清单

```
封面标题自检 · 逐条勾
[ ] 封面比例对平台(横 16:9 / 小红书 3:4 / 竖 9:16)?
[ ] 封面有脸 + 3–5 词加粗文案、占 ~20–30%、高对比描边、极简?
[ ] 标题前 3–5 词前置关键词?
[ ] 用了数字(尽量奇数)?中文用疑问句而非感叹句?
[ ] 有一个好奇缺口,且视频里真的闭合它?
[ ] 没有 最/第一/唯一 等绝对化词与承诺性表述?
```

## 失败目录(smells + 在 Manju 里长什么样)

| smell | 在 Manju 的表现 / 抓法 |
| --- | --- |
| 封面无脸/无文案/杂乱 | `manju package` 出的 cover 是空帧;`/packaging` 换 `cover.frame_ms` 选带脸的帧,或 card 模式加文案 |
| 标题含绝对化词 | 合规风险;本技能作 advisory 提示改写(Manju 从不发布) |
| 好奇缺口不闭合 | 与 `narrative-pacing` 交叉:末镜是否兑现;标题党拉高点击砸完播 |
| 封面比例错平台 | `packaging.yaml` 的 cover/画幅;竖屏项目用 9:16 |

## Manju 落地(把封面钉进 packaging)

- **封面**:`timeline/packaging.yaml` 的 `cover`——`mode: frame`(从成片抽帧,`cover.frame_ms`)或 `mode: card`(渲染文字封面,`cover.text`)。`/packaging`(round T)表单有实时卡片预览;封面从帧条上点选写 `cover.frame_ms`(`manju frames <source> --strip N` 出帧条)。
- **切封面/预告**:`manju package [--json] [--force]`——从当前 final 切封面 + 预告到 `exports/packaging/`(需先 `manju build` 出 final;`--force` 重切)。
- **预告**:`teaser` 两点范围(`from_ms` + `duration_ms`)。
- **标题/文案**:标题是发布物,Manju 不发布——把标题写进项目笔记/`story/`,本技能只给合规与 CTR 建议。
- 与 `narrative-pacing`(钩子同源:封面/标题是「第 0 秒的钩子」)配合。

## 验收 eval

1. 给一张空镜封面,是否改成带脸 + 3–5 词加粗文案?
2. 给一个关键词后置的长标题,是否改成关键词/数字前置 + 好奇缺口?
3. 给一个含「全网第一」的标题,是否去绝对化并改成疑问句?
