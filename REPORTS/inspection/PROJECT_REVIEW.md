# r16.7：从实际看图、输入和保存体验改进

基于实际可恢复的 r16.6（Git f49b49d2c431c9647003681ae9175cdca001832f，811 个提交），不是重造新功能区或重写媒体核心。

## 已复现的阻碍与处理
1. 导演原帧和精修目标图只有最高 230px 的缩略展示。新增独立只读图像查看器，适合窗口、100% CSS 像素、缩放、鼠标拖动/滚动、左右图切换和键盘关闭。保留原 URL 所指的原文件，不做 canvas 转制，不改变素材及批准。
2. 空提示词只有笼统报错，键盘焦点留在检查按钮。复用原来的验证器，仅补充字段元数据；主动检查失败时定位字段，说明下一步，保留原输入、原规则、旧异常文本和序列化协议。迟到错误不抢当前输入焦点；恢复不同文字后清除旧错误装饰。
3. 窄屏由搜索进入右侧工作区后，激活栏目还在屏外。只滚动横向导航，不额外移动正文。
4. 窄屏实际截图发现定位后标签被粘性栏遮挡，已改为定位整个字段标签。普通待备份提醒不再弹出遮住输入，仍更新原提示和底栏；实际错误/下载结果保留通知。
5. 80ms 重新计时式防抖会使连续输入期间底栏短暂沿用旧的绿色核验状态。改为按微任务合并状态核对，在下次绘制前反映修改，不用猜测是否属于创作字段，也不改真实备份判断。
6. 重复相同错误在手动关闭后可能不再显示，现允许新操作重新显示同一错误。审片中的“上方填写”改为指向真实的镜头工作区。

## 边界
查看器属于导演 PNG，不是任意格式图像编辑器、并排同步差异算法或 HDR/色彩验收。100% 指一图像像素对应一 CSS 像素，不保证设备物理像素比例。查看时暂停已有播放，退出不自行续播，不保存视图缩放/滚动到影片协议。图像弹窗内 Ctrl/Cmd+S 不触发网页或项目保存，关闭后再保存。

继续保留旧备份、关键帧精修交接、外部往返、素材重连、本机续作、完整长页、大字阅读和质量优先。三个模型政策文件（12 个视频档、质量名单、图像路线）逐字节不变。本轮未联网重排模型、未调用商业生成、未修改真实用户影片。
