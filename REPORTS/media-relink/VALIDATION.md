# 用户维护版 r16.3 验证报告

日期：2026-09-12。范围为当前实际源码及独立安装版，不代表全项目或 Windows 正式发布。

## 基线与改动
基于完整恢复、哈希复核的 MANJU_CONTINUE_FULL.zip，版本 0.2.0+r16.2，Git HEAD 53b5329952b4ec0fa18356f83c3f6ba3dc9caa43。本次是 0.2.0+r16.3 维护版，不把未恢复的原版 R17 当作继承来源。

新增跨工作区原素材重连：按内容哈希和大小查找已有记录的缺失绑定，支持改名、多用途、从已绑定工作区复用。保留任务、候选和历史，当前确认清除，质量优先开启。原片不转码，目标 PNG 不缩小；局部匹配允许先接回，完整保存仍要求媒体闭包齐全。

接回前必须预览并明确确认；文件在预览后改变会整体拒绝。过时预览同时检查文本/记录和 File 绑定对象，不依赖文件名。原视频实测尺寸/时长、导演 PNG 实测尺寸与记录不符会拒绝。缺失清单 TXT 是只读辅助，不包含媒体，不是备份。

修复续作请求超时仅覆盖响应头、正文可能无限等待的缺口。现在整个请求有 180 秒超时与 AbortController，迟到响应不变成成功保存；超时不等于服务一定没写入，页面要求重新查看恢复点。
