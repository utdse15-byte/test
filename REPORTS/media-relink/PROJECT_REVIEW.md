# r16.3 从实际使用出发的改进

本轮处理两件事：导入旧任务后不用逐区找素材；续作响应卡住时不无限等待或误报已保存。

既有的单区“添加素材”能按内容重绑部分记录，但把不匹配文件当新素材。新批量找回专门用于修复缺失绑定，不做添加与替换混合操作，覆盖镜头、审片、返工、导演底片和目标 PNG。它复用旧的内容哈希、元数据验证和 ZIP 格式，不另造工程格式，不锁定外部工具。

保留限制是有意的：不按相近名字猜原片，不把转码版视为原内容，不修改已经存在的绑定，不偷偷压缩来越过额度，不把缺失清单算备份。当前支持最多256个显式选择文件，不扫描磁盘目录；当前素材额度仍是单文件128MiB、全部引用去重后512MiB。

既有本机续作、下载核验和分段传输保留。新维护版不要求依次安装旧版。所有交付均为新路径，旧原包保持；完整包包含小工具入口，用户只需保存一份完整包和一份核验助手。

未增加商业API或便宜模型回退。模型名单不重新排名，不把历史资料伪装成当前最新证据。主影片项目和离线工作台仍分别备份。
