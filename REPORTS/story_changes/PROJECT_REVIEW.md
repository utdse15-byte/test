# 从 Fable 评审到可读故事差异

基线为实际 r16.9；完整读取 2026-09-13_17-31-26 评审状态。评审不是新应用代码，本轮不沿用任何丢失的早期 R17/长篇源码。

## 修复的已复现缺口

原 ide-preview 对故事只有两个摘要、story_changed 和简报复核状态。反转同一场动作时，fields 和 changed_fields 仍为空。原 21 项 IDE 测试通过，新测试要求显示原文/新文后先失败，随后实现；没有删除校验或用改记录替代修改。

新增独立派生模块 story_diff.py 及浏览器对等实现。两侧复用已有故事验证。实体由 stable ID 匹配，名称与数组位置不是身份；插入后移与原有相对顺序改变分开表达。字段覆盖测试要求未来增加的模型字段不能默默从对照消失。未改字段不重复携带正文，结构变化完整保留。

报告允许两侧为空，分别表示新增或删除；不同作品ID不配对场景。比较中的资料可能有作者计划，不能冒充对外无剧透上下文。代码不给出语义通过、模型身份或人工批准。

## 使用上的决定

先做派生只读对照，不以事务/存储迁移为前置。HTML报告在既有ide-preview上添加可选参数，原必填参数与命令数量保持。生成新文件，拒绝覆盖；对照纳入预览哈希，升级后需重新preview。

浏览器直接在既有恢复预览内展示当前与待恢复故事，不开新导航/审批页面。正文先展示，未改细节按需展开；窄屏上下排列，宽屏左右。所有用户文字作为text节点，不执行HTML。原父文档CSP保持。

读取/展开/取消不修改作品。后续输入使对照和旧确认失效。坏新故事导入取消旧预览但保留当前正文。恢复范围仍是整包，不提供假采纳按钮。常规核验成功已有就地提示，不再重复弹Toast挡住正文，错误仍会提示。

## 刻意没有实现

不做故事三方自动合并、选择性接受、人物关系图、长篇去重、常驻AI工作间或新增商业API。稿件分支/历史内容不删除。报告或哈希不复原缺失媒体，不读取其他窗口未提交的稿。“结局字段未改”不是“改动不会影响结局”。

原12视频档、质量名单和精修路线逐字节保持。底层媒体渲染、任务取消、原项目写入路径不改。未以本轮局部测试推进LAST_GREEN。
