# Manju · 看懂这次修改

维护候选 `0.2.0+r16.10`。包含 r16.9 的原功能，这次只把人物、剧情与场序的变化展示清楚，没有新增审批步骤。

## 本地 AI 完成修改后

AI 在原工作副本修改 STORY.json 后执行：

```text
python -m manju models ide-preview AI_WORK --html CHANGES.html
```

打开 `CHANGES.html` 即可看整段原文、新文、人物与依据、增删与位置变化、未改字段及简报复核状态。无需另外安装阅读器，不联网、无脚本，不能接受或执行修改。文件名必须没被占用。这个页面可能含作者私密计划，不默认对外发送。

命令仍输出原有 JSON 与 preview_sha256，并新增 story_diff。不要用 changed_fields 为空判断故事没有改变：changed_fields 仍指镜头、导演、返工等文字。

看完需要创建完整候选返回包时，仍使用现有 `ide-return`，并传入本次预览哈希。跨版本升级后重新预览，旧哈希不继续沿用。

## 网页里，不必先看 JSON

打开返回收工 ZIP 时，原恢复预览会直接展示故事对照。此处左侧是**当前页面**，右侧是**待恢复版本**，不是原导出基线与 AI 增量。你后来在网页写的内容也会显示。取消不会改当前工作；继续编辑会使旧预览失效，需重新打开。

原有恢复按钮仍然整体替换三个工作区和待处理材料，不是只接受一个场景。没有逐场接受按钮，没有自动三方合并。独立故事 JSON 导入也使用同样的对照；缺少故事或换了作品会明确提示，不按碰巧相同的编号配对。

## 看什么

场景名称可以改，稳定编号用于识别同一个对象；位置按实际顺序显示，第二场不等于编号 S02。新增前一场引起位置后移，不会把旧正文全标成重写。相同台词也不会跨场错配。

动作与对白以完整段落展示，未删除空白或换行。来源与知情范围、参考职责、旧版本及复盘变化也保留。没改的字段可展开查看，不挤满页面。

“作者结局字段未改”仅表示该字段内容相同，不保证人物动机与因果没有影响结局。报告不是模型来源证明、审片批准或素材备份。

## 最快体验

## 保存和使用边界

原 Story/v1、Desk/v1/v2 与 Studio/v1 格式不变；原 r16.9 可以打开新保存的收工包。对照/预览不是新作品数据，不写入收工包。重要正文、素材仍用顶部保存收工 ZIP，并选回实际文件核验，另留独立备份。

普通离线台不用 Python。完整源码和 CLI 请下载 FULL 包；实际 IDE/CLI 需要 Python 3.11+ 与依赖。主影片的媒体处理另需 FFmpeg。未保存网页不会被 IDE 读取。

没有自动接受、上传、生成、付款或降档。本轮不接通新的商业服务、不扩大长篇容量、不更改人物关系结构。Windows 实机、全项目回归、真实商业 IDE 客户端和整片渲染仍未认证。具体实测以 VALIDATION.md 与最终下载审计为准。
