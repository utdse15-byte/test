# UX / usability audit — three-axis backlog + disposition (2026-07-13)

## What was audited

A whole-repo usability sweep of Manju as it is actually lived-in, across three
axes: **owner experience** (the single Chinese-speaking Windows-11 owner driving
the CLI / GUI / board / installer daily), **AI-session DX** (what a fresh agent
session must excavate before it can safely work — CLAUDE.md sufficiency,
DECISIONS/REPORTS navigability, grep-pin/ownership discoverability, dev-loop
health), and **project health** (test-suite hygiene, drift guards, stale
records). The sweep produced **46 findings** (`raw_count: 46`).

## Method

Seven **read-only** auditors fanned out over disjoint areas (CLI ergonomics;
Windows cold-start; Windows real-usage papercuts; GUI/board; documentation
truth; AI-session effectiveness; test/dev-loop health). Each finding is
**evidence-cited** — a `file:line` reference or captured live command output —
never an assertion. Three lens rankers then scored every finding independently:

- **owner-value** — daily friction/damage prevented for the owner;
- **ai-dx** — context saved / traps avoided per future AI session;
- **risk-maintenance** — blast radius, pinned-surface exposure, and fit with the
  post-W1–W3 maintenance-mode rule (accept real-usage/data-loss/security/
  paid-safety/NLE bugs + provably-beneficial fixes; reject speculation).

Each finding's **avg** is the plain mean of the three lens scores; **votes** is
how many lenses scored it (2 or 3). Rows below are in the backlog's composite
ranked order. The full evidence strings, per-lens rationales (`whys`), fix
sketches and risk notes are the raw record — see the source JSON, not this
report:
`scratchpad/ux_backlog.json`
(`/tmp/claude-0/-home-user-test/5423e5fa-4083-51e8-92b2-b094c3966221/scratchpad/ux_backlog.json`).

Axis key: **owner** = owner experience, **ai-dx** = AI-session DX,
**project** = project health.

## Method honesty

- **Findings are evidence, not opinion.** Every one carries a `file:line`
  citation or captured live output (traceback text, curl responses, grep
  results, measured wall times); the read-only auditors changed nothing.
- **Scores are three-lens averages.** `avg` is the mean of owner-value, ai-dx
  and risk-maintenance; `votes` records whether a finding was scored by 3 lenses
  or 2. The composite rank is not strictly monotonic in `avg` — a lower-avg,
  3-vote finding can outrank a higher-avg, 2-vote one.
- **Duplicates are labelled, not silently merged** — the JSON's `duplicates`
  array lists the overlap groups; both members keep their own evidence.
- **The JSON is the raw record.** This report is a navigation/disposition
  projection; the full evidence strings and per-lens rationales stay in
  `scratchpad/ux_backlog.json` and are not reproduced here in full.
