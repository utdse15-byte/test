## 故障和边界

本机服务测试覆盖中断上传、错误哈希、非规范 ZIP、旧点保留、空间不足、目录额度、序列冲突、fsync/rename 故障、目标删除、跨进程目录锁和链接目录拒绝。HTTP 测试向真实服务发送请求，检查随机路径、Host、Origin、请求令牌、重复身份头、只读路由、拒绝任意文件访问和未开启时不创建恢复目录。

浏览器测试覆盖默认未启用、显式启用后的真实空闲延迟、上传时继续输入、关闭自动开关后禁止尚未发出的写入、删除本窗口最新点后暂停、恢复预览变旧、载入材料失败保留、不同窗口独立恢复序列，以及 pagehide/pageshow 的观察器重建。后者为事件模拟，不是原生历史导航验收。

修复了三处实测问题：本机恢复误用“独立备份已核验”；快速手动保存后观察器错误报未保存；关闭自动续作后仍可能发送尚未发出的保存。第一处以显式恢复来源协议解决，不依赖脆弱的点击事件顺序。源码和安装版都包含 restoreSourceVersion:1；旧页面与新服务混装会拒绝启动。

## 浏览器与平台的真实范围

沙箱对原生 file:// 和 localhost 浏览器导航返回 ERR_BLOCKED_BY_ADMINISTRATOR。native_navigation.json 原样记录这一结果，没有修改策略或弱化生产安全检查。

组合演练使用真实 Chromium 中的原页面内容，只有测试适配器将 fetch 转交给真实 HTTP 服务。服务器照常执行 Origin/令牌校验。它证明这组界面与协议协同，不等于原生浏览器端到端，也不等于 Windows 双击、安装、退出、升级回滚验收。

本机入口只用 Python 标准库，`python -I -S LOCAL_CONTINUE.py --help` 在隔离模式通过。但 Windows 文件锁、重解析点、强制关机、电源故障、不同文件系统和杀毒软件交互未在 Windows 实机验证。POSIX fsync 不能被扩大解释成所有平台断电耐久保证。

服务核验外层 Desk 容器、清单和内容哈希，不执行媒体也不做完整语义导入；恢复时继续由既有浏览器完整读取器校验内层结构与素材。哈希不是发布者签名，文件不加密；同操作系统账户和管理员可能读取恢复目录。

全项目未全量运行或重新收集，不能借历史 7000 多节点的收集结果宣称完成覆盖。没有安装 Hypothesis、Ruff 或额外依赖，没有把历史未执行模块标绿。正式发布绿灯未推进。
