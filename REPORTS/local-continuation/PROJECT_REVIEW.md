# 本轮用户使用梳理

## 这次解决的缺口
最常用的工作现场已经有可迁移收工 ZIP，但直接 HTML 关闭或刷新后，尚未手动保存的现场缺少恢复通道。只增加“记得保存”提示不能解决这个缺口。本次在不强迫安装完整应用的前提下，加入可选本机续作入口。

原 HTML 仍离线、仍不需要 Python。已安装 Python 3.11+ 的设备可以另外启动 LOCAL_CONTINUE.py，在页面主动启用本窗口续作。自动保存使用已有 Desk/v1 ZIP，包含三个工作区、已载入未接受改稿/模板和真实媒体。默认不开启，不在退出瞬间冒险保存，不依赖可能被清理的浏览器存储。

## 关键边界
本机恢复点与独立备份是两个概念。恢复点用于重新开始工作；硬盘故障和机器丢失仍要靠用户另存的收工 ZIP。由本机恢复不设置“已核验独立备份”，不恢复当前创作批准。

每次打开页面用独立身份，按窗口保留最近三份。成功发布新的不可变点之后，才能清理同窗口旧点；不跨窗口淘汰。额度上限 2 GiB、64 点，单包 520 MiB。大文件每次保存完整 ZIP，会有 CPU、内存和磁盘成本，未实现差分块缓存。宁可明确暂停，也不先删旧点制造空间。

服务只向本机随机端口暴露固定路由，使用随机路径、每次启动令牌与严格源检查。不提供任意磁盘读取、目录浏览、模型接口、远程访问或账号。它不是公网服务，没有云同步或加密。

## 没有顺手改掉的东西
原十二个模型能力档与质量名单不变。没有重新排名，没有自动降档，没有自动选择模型、付款、生成、审片、锁片或写回主影片工程。影片工程、NLE 项目、未绑定文件和临时预览仍需原专用备份。不是此前失踪 R17 的恢复声明。

## 后续真正仍需要验证的事项
Windows 原生双击与多浏览器本地访问、不同文件系统断电恢复、最大容量素材压力测试及真实用户设备权限。现有 Linux/隔离浏览器和小型真实媒体演练不能代替这些工作。当前交付保留明确候选状态，不推广为正式全绿发布。

## 下载优先
完整包、小上手包、配套内容校验助手和五段无损传输均从相同源码制作。小包含实際合成媒体示例，用户无需先找素材才能确认基本操作。原文件不覆盖；发布门失败就不展示猜测链接。
