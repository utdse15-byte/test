# R4 功能重建验证

这是 R3 重建版上的累计代码，不是原 R4 字节恢复。旧 R2 交接格式和人工选片边界保持不变。

实现：8 个作者档、28 个任务模式；严格 schema、型号/角色/时长/分辨率组合、来源时间、参数未知告警；请求与目录哈希绑定的人工批准；真实文件复核、独占新目录封包、语义及字节篡改检测；catalog/example/plan/approve/bundle/verify/diff 七个 CLI 命令。

最终相关回归：81 passed。范围包含新增作者适配测试、R3 本地运行恢复、R2 素材交接、FFmpeg 取消单元测试，范围重叠不可累加。
原始记录：包内 EVIDENCE/r4-final.xml 和 r4-final.log。

实际演练：FFmpeg 创建两张真实 PNG，中文首尾帧文件名；MiniMax H3 首尾帧任务经过规划/人工声明/封包/验证，调用完整 `python -m manju models verify` 返回成功。修改 BRIEF 后被拒绝；源 PNG 字节未变。没有商业生成调用。
原始记录：EVIDENCE/r4-rehearsal/RESULT.json；复现脚本 source/tools/rebuilt-delivery/rehearsal_r4.py。

严格边界：图像宽高、媒体编码及部分供应商限制尚不由本模块完整探测；声明式视频时长不等于实测；自然语言约束只做精确文本冲突校验。批准是本地声明，不是认证签名或花费授权。final 草稿哈希在本阶段仍是声明，不冒充审片记录验证。
Windows 实机发布门仍未关闭。没有重跑全项目 6403 项完整范围，也没有修改 LAST_GREEN。
