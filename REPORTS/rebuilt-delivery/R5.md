# R5 离线工作台验证

R5 累计继承本轮 R3/R4 的真实 Git 提交。不是给 R4 改名字：新增单文件 HTML 工作台与只读影片镜头桥接。

## 实际功能

双击 HTML 的设计入口，不依赖服务器、CDN、Python 或外部模型 SDK。任务表单、具体模式检查、素材分工、纯本地流式 SHA-256、素材重绑定、明确批准、完整素材 ZIP 下载。
同一个文件可以按不同逻辑用途复用，封包只复制一次；已导出或导入的任务通过内容哈希重新识别素材，不要求原文件名相同。
`manju models from-shot` 只读导出原镜头、参考图谱和控制上下文；`manju models workbench --output ...` 从安装版导出完整 HTML。
旧 R4 的真实交接包已作为固定兼容样本保留并通过新版本验证器，没有把默认字段扩展偷偷改变旧审批哈希。

## 验证结果

最终相关范围：106 passed，1 skipped。包含 R5 浏览器/核心测试、R4 作者档、R3 运行恢复和 R2 交接保护，彼此有重叠，不能与其他报告累加。
原始记录：EVIDENCE/r5-final.xml、r5-final.log。

浏览器使用 Chromium 144.0.7559.96，执行产品 HTML 的真实字节，真实文件读取、表单填写、角色绑定、审批、Blob ZIP 下载；下载出的 ZIP 经 Python zipfile CRC 与独立 authoring verifier 全部通过。
测试覆盖 SHA-256 已知答案与分块/填充边界、Python/JavaScript 计划和哈希一致性、无自动型号选择、缺失素材拒绝、改名重绑定、XSS 文本显示、390px 无横向溢出、旧 R4 包兼容。
实际演练记录 EVIDENCE/r5-rehearsal/RESULT.json；截图、浏览器下载 ZIP 和解压后的真实 PNG 均保留。

## 不可省略的环境边界

本沙箱的管理策略拒绝浏览器导航到 file://，也在路由拦截前阻止测试域名。首次测试原始失败保留于 r5-first.log/xml，不删除、不改写。
后续浏览器用 isolated_document 注入完全相同的本地 HTML 字节，真实执行脚本和下载；没有伪装 file:// 双击已经通过。该模式通过环境变量 MANJU_BROWSER_TEST_TRANSPORT=isolated_document 明确选择，不静默降级。
唯一跳过项是 file:// reload + localStorage 的实机持久化检查。隔离文档中存储不可用时，页面明确提示导出备份；此退化路径实际测试通过。
Windows 双击、浏览器文件权限、安装和运行仍需要用户环境确认。

## 范围限制

工作台不产生模型视频、不替用户登录、不消费额度、不选择影片候选或锁片。
浏览器单文件 128 MiB、总文件 512 MiB 是本地安全上限，不是供应商能力限制；更大的文件用 Python 交接命令。
草稿本地存储只作临时恢复，下载 JSON/ZIP 才是用户控制的备份。页面只能触发下载，无法替浏览器确认用户保存成功。
