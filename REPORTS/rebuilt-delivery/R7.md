# R7：可下载、可恢复、可直接打开的累计候选版

## 版本事实

以已验证 R2 `13a2ab12dac109bece5a2be63254024c11ebc390` 为基础，累计包含本轮 R3、R4、R5、R6。
原版 R3/R4 ZIP 没有找回；这是核心功能重建及后续改进，不能声称字节级恢复或与丢失代码完全等价。
各阶段独立封包并原样保留。R7 提交身份、源码树和阶段祖先关系由 PACKAGE.json 与 VERIFY_PACKAGE.py --git 验证，不依赖聊天中的版本描述。

## 本版新增

原影片工作台新增“模型”入口；从绑定工程只读导出镜头任务，用户再明确导入，不自动覆盖浏览器草稿或工程。
离线页面、HTTP 入口与 CLI 共用一份生成 HTML；能力规划和审片逻辑没有分别维护两套不同版本。

下载前后的校验分别处理：ZIP_CHECK.py 检查整包 SHA-256、CRC、危险路径、链接、重复条目、Windows 大小写/Unicode 冲突和体积上限；只解压到不存在的新目录。
VERIFY_PACKAGE.py 比对精确文件清单、源码/wheel、源码版本身份，另可克隆 Git、验证全部阶段祖先并重放 R2 补丁。
文件哈希不是发布者数字签名，也不是用户端点击保存成功的证据。

LAUNCH.py 先核验，再诊断、打开 HTML、显式安装或启动。
安装只创建新的私有 .venv，拒绝覆盖已有环境；默认不联网，Windows 安装入口会提示后由用户输入 INSTALL 才下载依赖。
离线依赖目录由 --wheelhouse 明确指定，不往封存包里塞新文件。
启动核对实际安装版本，只监听 127.0.0.1，并强制 strict_zero_cost；真实影片工程必须在交付目录之外。
诊断不导出环境变量、令牌或个人路径。Windows 批处理已做语法结构/路径引用测试，但没有 Windows 实机执行。

新模型命令和协议正式进入原项目兼容性清单。原有154条命令的必填参数均未改变，新增14条命令；新增10个 schema 保持 experimental，不把其登记表引入运行时。

另有小体积离线工具 ZIP：只需解压后打开 HTML，可规划、交接、候选审片、导出记录和定稿包。它不包含完整影片应用，不生成商业模型视频，也不是媒体依赖安装器。

## R3/R4/R5/R6 功能继承

R3：本地进程真实取消、取消不启动回退、清理不确定时拒绝冒称已停止、截图先验证后原子提交、已完成候选保留。
R4：逐型号逐模式约束、保留/改变字段、请求和能力档哈希绑定的人工声明、不可变交接；旧项目制作包不原地改写。
R5：无外部依赖的离线工作台、素材哈希、真实浏览器 ZIP 下载、只读镜头任务导入。
R6：实际候选视频、A/B 隐藏名称呈现、人工记录链、草稿晋升；新定稿包必须包括实际批准草稿与审片证据。没有自动选片或 Picture Lock。

## 实际运行证据

源代码和隔离安装的250个运行时文件逐项相同；使用宿主已安装依赖，不是全新电脑成功安装。
源码与安装版都执行了生成中取消、保留完成候选、恢复生成、测试夹具显式选片、六秒三镜成片、缓存复用、成片重编码中取消。
两版最终MP4哈希相同，取消不改变旧成片，完整解码通过。

真实 Chromium 截图进程启动后发出取消，本次约0.295秒响应；观察到的进程停止，旧封面字节未变，独立观察进程仍运行。
这不证明 Chromium 正常截图路径全面通过，更不是 Windows 进程树证明。

真实视频审片演练在 Chromium 中播放两个合成候选、写入明确测试声明、实际下载审片JSON、晋升、下载定稿ZIP；Python独立校验实际草稿、审片记录链和请求，原视频哈希未变。
原界面以真实只读HTTP输出任务，再在浏览器导入和下载，同一工程55个文件哈希未变。
沙箱阻止直接 file:// 和本地网址导航，因此浏览器使用原HTML的isolated_document传输；没有绕过限制，也不把它冒充原生导航或Windows双击实测。

离线安装缺少第三方依赖的真实负向演练按预期失败，只删除本次创建的未完成 .venv，原封存包再次校验通过。
没有把缺依赖的离线安装写成成功，没有捏造“一键完整离线安装器”。

## 使用入口

先完整解压到新的短路径目录。最快入口是 OPEN_MODEL_WORKBENCH.html，不需要Python或模型账号。
完整影片应用的安装、启动、核验和诊断见 QUICKSTART_ZH.md；不要覆盖旧版和真实影片。
浏览器导出后，请在下载列表确认文件已保存，并同时备份任务/审片JSON和原视频。
