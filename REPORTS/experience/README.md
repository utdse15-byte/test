# Manju 体验维护版 · 0.2.0+r16.6

## 先打开工作台，不必先安装完整影片应用
完整包或上手包完整解压到一个新目录，打开 `START_HERE.html`，点击“打开工作台，开始创作”。普通离线页面不需要 Python、账号或网络。完整包已包含上手包的页面和示例，不必两份都下载。保留旧版本与真实影片工程。

这次改版的是离线创作工作台，不是主影片应用的时间线。既有素材、外部往返、质量名单、批准与备份协议不变；没有自动生成、上传、付款或降档。

## 日常只记这几件事

**左侧选工作，顶部打开与保存。** 开始与保存、镜头与素材、审片与定稿、导演与精修、局部返工、外部协作、组合与模板，分别展示当前任务。窄屏时任务导航横向滚动，页面不被长文件名撑宽。

**切换不会重建表单。** 草稿、已绑定文件、当前操作留在原位，回到工作区会回到之前的滚动位置。切走正在播放的视频会暂停，播放位置保留，切回来不会自行播放。若点击具体定位结果，则会滚动到该操作。

**随时保存，不必回首页。** 顶部“保存收工包”或 Ctrl+S（macOS 为 Cmd+S）调用原收工保存动作，包含三个工作区及已载入待处理改稿和模板。发起下载不等于已保存到电脑；到首页选回实际 ZIP 核验，底部才显示当前备份已核验。继续输入会重新提醒未备份。保存范围与旧版一致，下文有完整边界。

**不记功能在哪。** 点击“快速找到”或 Ctrl+K / Cmd+K，输入“精修”“模板”“找回”“备份”等词。上下键和 Enter 定位，Esc 退出并返回原来焦点；搜索只查功能入口，不搜索或上传你的影片内容，也不直接执行批准、生成或删除。

**字太小就放大。** 桌面顶部“大字阅读”可以切换；窄屏可通过“快速找到”搜索“大字”。该偏好与当前导航、滚动位置只在本次页面中保留，不进入影片与收工包，不是新的待备份创作内容。

**喜欢旧式长页仍能切回。** 左下“完整长页视图”展示所有工作区；再点击可回到分区模式。所有原入口继续存在，兼容旧说明里的第 06 / 07 / 08 / 09 区称呼。低频的兼容工具和说明默认折叠，点击即可展开，不需要重新导入素材。

## 马上体验已有工作
在顶部点击“打开材料”，选择包内 `EXAMPLES/CHECKOUT.zip`。这个内层 ZIP 不用解压。先看识别与恢复预览，明确确认后即可播放合成视频、继续编辑，试着切换工作区再保存。示例是测试素材，不是你的真实作品或批准。

`EXAMPLES/RETOUCH/` 保留上一版的关键帧精修示例，用于“导演与精修”内的独立往返。普通收工仍用顶部保存。只打开发布安装包或一整个示例合集，不能被当作任意工程导入；应选择里面的具体工作文件。

## 下载后，选回真实文件核验
配套 `MANJU_EXPERIENCE_DOWNLOAD_HELPER.zip` 解压后打开 `OPEN_DOWNLOAD_HELPER.html`，选择完整包或上手包。按实际大小和 SHA-256 判断一致，不看文件名、不上传。

大包下载不顺时，下载本轮五个 `MANJU_EXPERIENCE_PART_01.zip` 至 `05.zip`，在助手中一次选中。分段不解压，不用排序。核验后保存完整 ZIP，再选回实际落盘文件核验。恢复出来的字节应与直接下载完整包一致，最终发布收据记录实际核验结果。

附件不是永久网盘；保存到自己的备份位置。哈希证明内容一致，不证明发布者身份或电脑磁盘已拥有第二份安全副本。

## 既有能力：关键帧精修往返
在“导演与精修”工作区中选择原片、抓取时刻原帧、填写每个时刻的目标外观与共用保留/改变要求，然后展开“把关键帧带去顶尖图像工具精修，再批量接回”。

明确选择外部入口，可自行选择顶尖工具，或使用有日期身份的 OpenAI Sunburst 精修说明。页面不会发请求或代付。资料核验日2026-09-12，复核日2026-09-19；这是官方能力定位，不是本项目独立画质排名。其他平台的同名选项不保证接受同一组参数。

点击导出精修ZIP，解压后使用 `PROMPTS/A01.txt` 等逐张要求，上传对应的 `INPUTS/` 原帧和已有目标图到自己的工具。每张输出PNG，按任务指定名字保存；原画幅可以更高分辨率，不能只改扩展名将JPEG伪装成PNG。请保留未改动的 `TASK.json`。ZIP故意不含运动原视频，所以不是完整备份。

回到同区，选择原 `TASK.json` 和一批返回PNG，预览后明确确认。可先接回一张，第二张回来时用同一任务继续。会核对底片、时刻、原帧和要求；如果本地已修改了某张目标图，拒绝覆盖它。名字正确不证明模型、画质或版权；返回仍只是未批准的目标图，必须亲自审查。

图片通过完整浏览器解码再应用，尺寸可高于原视频但画幅必须一致。返回图片的原始字节保留，不缩图、不裁切、不压缩。浏览器抓取的原帧是SDR参考，不是HDR/EXR母版，播放毫秒不是认证帧编号。接受新目标后不删除磁盘旧图，但当前绑定会替换，先另存原导演包有助于回退。

**保存范围要区分：** 已接回目标图进入原导演/Studio/收工包；尚未应用的精修任务、返回文件和临时预览不在旧收工格式内，应单独保存导出ZIP和PNG。没有修改老备份协议，没有自动备份或上传。

## 直接体验示例
包内 `EXAMPLES/RETOUCH/` 含真实合成素材。在“导演与精修”的“核验并重新打开导演ZIP”恢复 `DIRECTOR_BEFORE.zip`（此文件不用解压），再选择 `TASK.json` 和 `A01_..._TARGET.png` / `A02_..._TARGET.png` 预览接回。两个1920×1080目标图是纯合成测试，不是付费AI作品或用户批准。

脚本用户可运行 `manju models retouch-verify RETOUCH_KIT.zip`。它只读核验文件结构、内容校验值与PNG头，不证明完整图像解码、模型来源或质量。返回应用仍在工作台明确确认。

## 保留的本机续作：找对恢复点，再继续
已有的恢复点检索位于可选本机续作入口。已有 Python 3.11+ 时运行 `OPEN_CONTINUE_WINDOWS.cmd` 或 `python3 LOCAL_CONTINUE.py`。普通直接 HTML 仍然可用，不会显示不存在的恢复目录或假装已自动保存。

点击“查看已有恢复点”，再点“读取内容摘要（只读）”。摘要显示镜头、命名方案、提示词摘录、素材数量、候选及历史审片数、返工/导演材料，以及是否有未处理的外部改稿和模板。输入关键词筛选，再使用原来的“核验并预览恢复”，最后明确确认。读取不会改动当前草稿、恢复点、素材和批准状态。

第一次不自动读取；每次主动点击都会重新检查实际文件 SHA-256，坏点保留并标明摘要未通过。一个坏点不会挡住其他点。摘要只在本页内存中暂存，刷新后重新读取；既有 POINT.json、DESK.zip 和 STUDIO 格式不变，也不创建新的索引数据库。

每份提示词、返工和导演要求只显示前 240 字符；镜头/方案/模板名显示前 160 字符。筛选只查这些摘要和时间，不是全项目全文搜索。读大恢复点需要扫描完整文件，可停止读取后续摘要；正在进行的那一份仍要完成或超时。不扫描恢复目录外的文件、不解码视频、不上传到云。

展开区域改为显式显示/收起，支持键盘并在收起后回到列表按钮。正在读摘要时仍可输入，读完后有新文字就显示尚未保存，不沿用旧的成功保存消息。坏点摘要不等于可删除；需要保留时先另存原收工 ZIP 检查。

本窗口保留最近三份成功恢复点的顺序改按保存序号，电脑时间倒拨不再把较新的点误判为旧点。新点完整发布之后才清理自己的旧点，其他窗口不受影响。列表时间只是显示用，不保证电脑时钟正确。

## 文件改名、搬家：一次接回原内容
在工作台首页展开 **“素材改名或搬位置了？按内容批量找回”**。

先打开已有任务或记录，再点击“检查缺失素材”。选择一批可能的原文件，等待只读核对，查看匹配结果后，明确勾选并点击“接回匹配的原文件”。程序按 SHA-256 和字节数匹配，不看名字是否相同。一个原片用于多个地方，只需找到一份，就能修复相应缺失用途。

已在另一区域绑定的原文件，也可点击“从已绑定工作区找回”，不用再找磁盘位置。还没找齐时，可以“导出缺失清单 TXT”，带着原名、用途、大小和完整内容校验值去找。清单不包含媒体，不是备份，不消除未备份提示。

只修复缺失绑定，不替换已有绑定、不添加新候选、不改文字、素材角色、镜头身份或历史决定。当前确认会清除，质量优先开启。预览后继续写字、改变素材，旧预览失效；接回前重新读取原文件，变化就整次拒绝。匹配一部分可以先接回这一部分，但完整备份仍要求全部需要的素材齐全。

原片、PNG 和目标图不转码、不缩图。视频按已有记录复核尺寸和时长，导演 PNG 复核尺寸；这不是画质审片、完整帧解码或 HDR 认证。改剪、重新导出、重新编码都是新内容，即使同名也不能接回旧记录，请作为新素材使用原入口导入。

一次最多选 256 个文件；单素材 128 MiB、全部引用去重后 512 MiB 的原有限制不变。不自动扫描文件夹或整个硬盘。不包含主影片工程的离线素材重连。

## 日常收工
用首页“保存收工包 ZIP”，在浏览器下载列表确认保存，再用“核验已保存的收工包”选回。收工包包含三个工作区、实际媒体、已载入未接受的外部改稿、个人模板和相关文字。原协议不变，可返回原 r16.5 使用。

主影片工程、外部剪辑工程、未绑定文件、未应用能力档或组合预览、临时撤回点和播放器位置仍不在收工包里；主工程目录需要另行备份。

## 可选本机续作
已有 **Python 3.11+** 的 Windows 设备，双击 `OPEN_CONTINUE_WINDOWS.cmd`；其他系统运行 `python3 LOCAL_CONTINUE.py`。只用标准库，不安装第三方库。启动后主动开启“在本窗口开启自动续作”，或点“立即存一份恢复点”，才开始写入。默认不写。

恢复点在用户主目录 `ManjuRecovery`，独立于软件解压位置和浏览器缓存。重新启动服务后，查看、核验预览，再确认恢复。每窗口成功保存新点后保留自己最近三份，不清理其他窗口。默认上限 2 GiB、64 份；没有足够空间时先暂停，不先删旧点。

停笔约 8 秒后尝试保存，相邻自动保存至少间隔 30 秒；关窗瞬间不承诺保存。这个版本给**完整响应正文**加上超时约束，卡住会释放操作状态而不是永远显示处理中。超时只表示客户端没确认，不证明服务器一定没写入；重新查看恢复点后决定下一步，不要关闭还有未保存文字的页面。

本机恢复点不是独立备份，不能防硬盘故障或机器丢失。只有最近成功写入的现场能恢复；保存期间继续写的文字不被标成已保存。必要时“另存收工 ZIP”，并放到第二个安全位置。

## 完整影片应用与限制
完整包的 `APP/INSTALL_WINDOWS.cmd` 需要已有 Python，明确输入 INSTALL 才创建私有环境；成功后使用 `APP/START_WINDOWS.cmd`。影片渲染另需 FFmpeg／FFprobe 及项目依赖。上手小包不含影片应用安装包和源码历史。

本机服务仅绑定环回地址，固定路由与令牌，不作为公网或多人共享服务；恢复文件不加密、不含身份签名。直接 HTML 受限时，已有 Python 可用 `OPEN_LOCAL_WINDOWS.cmd` 只读备用入口。Windows 实机双击、安装与退出尚未验收，隔离浏览器演练不等于原生 Windows 端到端验收。

本版本基于真实可恢复的 r16.5，保持十二个能力档和质量名单，不冒充以前失去的原版 R17；没有商业生成调用、自动降档、云上传、选片或锁片。
