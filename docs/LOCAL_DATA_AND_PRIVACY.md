# 本地数据与隐私边界

Manju One 是 Windows-first、单用户、本地优先的个人电影工作台。本页说明产品在默认本地使用、严格零成本验证和未来受控云端使用时，哪些数据会被读取、保存或发送。

## 默认本地工作台

- GUI 由本机 loopback HTTP 服务提供，默认只绑定 `127.0.0.1` / `localhost`。
- Manju 不上传产品使用遥测，不嵌入远程分析脚本，不从 CDN 加载 UI、字体或图标。
- 浏览器页面默认拒绝摄像头、麦克风、位置、支付、USB、串口、蓝牙等环境权限。
- 项目文本仍是唯一 canonical truth；媒体保持 append-only。
- 浏览器布局、最近页面、播放偏好和任务提醒属于可删除的用户界面状态，不参与 build、Provider 请求身份或 Picture Lock。

## 本机会保存什么

### 项目目录

包含用户可审查的故事、镜头、规则、时间线、媒体、导出物和事件证据。Manju 不会在卸载时删除 `*.manju` 项目。

### 用户级配置与状态

默认位于用户主目录或 `%LOCALAPPDATA%\Manju`，可能包含：

- 最近项目；
- GUI 工作位置与偏好；
- Provider manifest 和凭据引用；
- Windows App 启动会话记录；
- UTF-8 启动日志；
- 可删除缓存。

这些内容不是故事或镜头真相。卸载默认保留项目和用户配置；日志只有显式要求时才删除。

## 严格零成本模式

`MANJU_EXECUTION_MODE=strict_zero_cost` 时：

- 外部 Provider transport 在发送前被拒绝；
- 云端凭据不会被读取；
- localhost 假 Provider和本地 FFmpeg 路径仍可用于无费用验证；
- 免费额度、试用金和按量云 API 也不属于零成本测试范围。

应用栏与 **帮助与支持（F1）** 会长期显示当前执行模式。未知的非空执行模式会 fail closed，而不是静默回到可联网状态。

## 未来受控云端模式

未来用户主动启用云端 Provider 时，只有明确选择的任务数据才会按 Provider manifest 发送。Manju 仍要求：

- Provider、模型、地域和请求参数可见；
- 预算、最大可能费用和币种在传输前可见；
- 当前会话人工确认；
- submission identity 在网络前持久化；
- 模糊提交不自动重投；
- 本地取消不冒充远端已经停止或停止计费。

具体供应商的数据保留、训练和地域政策不由 Manju 代替供应商承诺，启用前应单独核对。

## 帮助、诊断与支持包

**帮助与支持（F1）** 只读取一个有界、无密钥的产品快照：版本、操作系统类别、Python 版本、执行模式、项目显示名和只读状态。它不会读取：

- API Key 或 token；
- Provider 配置正文；
- 项目绝对路径；
- 主机名或用户账户；
- 媒体内容；
- 环境变量列表。

更深入的诊断必须由用户显式运行：

```text
manju doctor
manju support-bundle
```

`support-bundle` 采用默认拒绝的脱敏收集器，并在写入前自检密钥和路径标记。生成支持包不等于发送；是否分享始终由用户决定。

## Windows App 日志

无控制台的开始菜单入口把启动故障写入：

```text
%LOCALAPPDATA%\Manju\Logs
```

日志用于恢复启动问题，不是遥测。默认只保留有限数量；卸载不会自动删除，除非用户显式选择删除日志。

## 安全报告

本地 GUI 仍是 HTTP 服务。发现安全问题时，不要公开附带项目、密钥或日志原文；先生成脱敏支持包，并在分享前人工检查内容。
