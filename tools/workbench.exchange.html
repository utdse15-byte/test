09 · 外部工具往返

把内容带出去，带回修改而不是覆盖。

选择要交给外部工具的区域。文字可以用编辑器或外部模型改，原图、视频和音频按原字节带走。返回后逐字段比较导出原文、当前本地与外部修改；只应用你确认勾选的字段。

导出可编辑材料

ZIP 解压后有 EDIT.json、独立 texts/*.txt、素材用途映射与带扩展名的 media/ 文件。修改 JSON 的 values，或者修改独立 TXT。只回传 JSON / TXT，不需要重新打包 ZIP。可用空白清空字段，不会自动执行。

取回外部文字，逐项选择

尚未加载修改。TXT 必须与本次 EDIT.json 的编号对应；UTF-8 BOM 可接受，CRLF/CR 会明确转为 LF，其他空白保留。

三方比较：原文 / 当前 / 外部

冲突默认不选；底片、镜头身份或关键帧已换的旧修改不可强行套入。未勾选项保留当前本地内容，原素材、能力目录和审片历史不变。

导出交换材料不是备份，不会清除未备份提醒。关闭页面前另存总备份，外部改稿缓冲区不包含在总备份中，请用“另存未应用的外部改稿”单独保存。

哪些能往返，哪些不能假装通用导入？

原影片工程：已有 manju pack / manju unpack；页面三个工作区：总备份与单区 ZIP；模型能力档：JSON 预览替换；个人模板：JSON。

剪辑：Manju 自己导出的 OTIO、FCPXML、剪映差异骨架有受限回程，需原导出基线并逐项确认；任意外来 FCPXML、EDL、OpenClap 只生成导入计划，不等于已还原整个工程。字幕、样式、特效并非所有格式都双向无损。

外部媒体结果：用第02区按用途绑定；候选用第05区添加；精修目标图用第07区对应锚点绑定。媒体内容变了就是新文件，不按文件名静默替换旧候选。此区只把文字带回，不导入脚本、账号、批准或任意工程文件。

原片和目标图都可能含隐私；只勾选需要分享的区域。说明/映射只作材料清单；文件哈希不证明作者身份、版权或模型质量。
