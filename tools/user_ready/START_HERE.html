MANJU / R16 维护版 / 0.2.0+r16.5

把关键帧交出去，精修后接回来。

这里是实际使用入口，不是安装向导。先把整个 ZIP 解压到新目录，保留旧工程和旧版本。

01 / 开始使用

打开创作工作台

镜头、外部改稿、返工、导演材料和收工包沿用 R16。没有增加账号、云同步或付费生成。

进入创作工作台

直接打开 HTML 不需要 Python。后面的本机启动方式只是备用，不会自动安装软件。

关键帧去外部顶尖工具精修

进入工作台第 07 区，展开“把关键帧带去顶尖图像工具精修，再批量接回”。填写每个时刻的目标外观，明确选择外部精修入口，导出实际图片与逐张提示词。

外部结果按任务指定名字保存为 PNG。选回原 TASK.json 和结果，核验预览后明确确认。只绑定待审目标图，不生成、不付款、不自动选片。精修包不含原视频，不替代收工备份。

素材改名或搬了位置？

进入工作台首页，展开“素材改名或搬位置了？按内容批量找回”。选择一批可能的原文件，先预览，再明确接回。只接回原内容，不按名字替换新版本、不修改原稿。

已有素材在另一工作区时，可以点击“从已绑定工作区找回”。还没找齐时导出缺失清单；清单不包含素材，也不是备份。

容易误刷新？可选开启本机续作

已有 Python 3.11+ 的 Windows 设备，双击 OPEN_CONTINUE_WINDOWS.cmd；其他系统可运行 python3 LOCAL_CONTINUE.py。不需要安装第三方库。

服务打开工作台后，先主动勾选“在本窗口开启自动续作”，或点击“立即存一份恢复点”。没有勾选或保存就不会写入。恢复仍先预览，再明确确认。

恢复点保存在用户主目录的 ManjuRecovery，不在浏览器缓存中；每个窗口只在新点保存成功后清理自己的旧点。总容量达到上限会暂停，不会先删除旧点来换空间。浏览器没有自动打开时，复制控制台里的本机地址。

找不清哪份恢复点？点击“查看已有恢复点”，再“读取内容摘要（只读）”，按镜头、方案或内容摘录筛选。先看素材、返工与待处理意见摘要，再核验并预览恢复。摘要不上传、不覆盖当前新稿，长文字仅显示摘录。

请保留启动窗口。它只帮助恢复最近已成功写入的现场，不能保护硬盘故障、尚未保存的最后输入或主影片工程。收工仍需另存 ZIP。

先确认这个浏览器能保存文件

先下载一份很小的测试文件，再选回。只验证保存与读取这一步，不替代真实影片或完整应用验收。

尚未确认保存。不会读取或上传其他文件。

03 / 尝试一次恢复

用附带示例，不动真实作品

另存收工包示例，或在解压目录直接找到 EXAMPLES/CHECKOUT.zip。

进入工作台，选择“打开文件 / 拖入材料”，载入示例，再核验、预览、确认。示例 ZIP 不用解压。其中是合成视频和未接受意见，不是你的真实作品。

退出前在工作台保存收工包，再选回核验。直接 HTML 与只读本机入口不自动保存。只有通过续作入口启动并主动开启，才会创建本机恢复点。

遇到问题，只走需要的那一步

页面空白，或直接打开 HTML 受限制

已经完整解压后，在 Windows 双击根目录 OPEN_LOCAL_WINDOWS.cmd；其他系统可运行 python3 LOCAL_WORKBENCH.py。这条只读备用路径需要已有 Python，仅在 127.0.0.1 随机端口提供三个经过校验的只读文件，不扫描磁盘、不上传、不安装依赖。

没有自动打开浏览器时，复制终端中本机地址。完成并保存收工包后按 Ctrl+C 退出。请勿把它部署成公网服务；公司设备政策仍可能阻止本机访问。

下载中断、包太大或解压报错

先用下载校验助手核对实际文件。完整包也提供五个小分段，配套助手能直接读取分段 ZIP、核验并合成为同一份完整包；不用先解压分段，也不用命令行。

分段链接和助手在本次聊天交付中。这里只是另一种传输方式，不是减配版或增量升级包。

我需要完整影片应用

完整包的 APP/INSTALL_WINDOWS.cmd 需要已有 Python 3.11+，明确输入 INSTALL 后才创建独立环境。成功后再用 APP/START_WINDOWS.cmd。影片渲染还需要 FFmpeg/FFprobe 及项目依赖。

保留此前对旧 R16 运行时自报 R15、被安装门拒绝问题的修复。当前程序与安装包都标识为 0.2.0+r16.5；这是从可恢复的 r16.4 继续开发的维护版，不冒充此前丢失的 R17。

仅上手小包不含影片应用。完整包可运行 DIAGNOSE_WINDOWS.cmd 做只读检查，日志位于 APP/local-logs/；不包含环境变量、用户路径或影片内容。

不确定是否保存完整，或想搬到另一台电脑

保留下载包、校验助手以及已核验的收工 ZIP。主影片项目目录和外部剪辑工程另行备份。附件不承诺永久在线，第二份本地备份比再次翻聊天可靠。
