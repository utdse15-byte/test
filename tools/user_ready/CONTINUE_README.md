# Manju 用户维护版 · 0.2.0+r16.3

## 打开就用
把完整包或上手包**完整解压到新目录**，打开 `START_HERE.html`，点击进入工作台。普通离线入口不需要 Python、账号或登录。完整包已经包含上手包的工作台，不必两份都下。保留旧版本和真实影片工程，不覆盖。

下载后，用本轮的 `MANJU_RELINK_DOWNLOAD_HELPER.zip`，解压并打开 `OPEN_DOWNLOAD_HELPER.html`，选回实际下载的完整 ZIP 或上手 ZIP。文件改名不影响内容核验。大文件下载困难时，把五个 `MANJU_RELINK_PART_*.zip` 全部下载，一次选中交给助手核验合成；分段不用解压、无需排序。保存合成结果后，再选回一次。助手只读取你选择的文件，不上传。

这里核验的是实际字节完整性，不是发布者签名，也不代表已经保存在另一块硬盘。附件不承诺永久在线；下载包、助手和创作收工包应保存在自己的安全备份位置。

## 文件改名、搬家：一次接回原内容
在工作台首页展开 **“素材改名或搬位置了？按内容批量找回”**。

先打开已有任务或记录，再点击“检查缺失素材”。选择一批可能的原文件，等待只读核对，查看匹配结果后，明确勾选并点击“接回匹配的原文件”。程序按 SHA-256 和字节数匹配，不看名字是否相同。一个原片用于多个地方，只需找到一份，就能修复相应缺失用途。

已在另一区域绑定的原文件，也可点击“从已绑定工作区找回”，不用再找磁盘位置。还没找齐时，可以“导出缺失清单 TXT”，带着原名、用途、大小和完整内容校验值去找。清单不包含媒体，不是备份，不消除未备份提示。

只修复缺失绑定，不替换已有绑定、不添加新候选、不改文字、素材角色、镜头身份或历史决定。当前确认会清除，质量优先开启。预览后继续写字、改变素材，旧预览失效；接回前重新读取原文件，变化就整次拒绝。匹配一部分可以先接回这一部分，但完整备份仍要求全部需要的素材齐全。

原片、PNG 和目标图不转码、不缩图。视频按已有记录复核尺寸和时长，导演 PNG 复核尺寸；这不是画质审片、完整帧解码或 HDR 认证。改剪、重新导出、重新编码都是新内容，即使同名也不能接回旧记录，请作为新素材使用原入口导入。

一次最多选 256 个文件；单素材 128 MiB、全部引用去重后 512 MiB 的原有限制不变。不自动扫描文件夹或整个硬盘。不包含主影片工程的离线素材重连。

## 日常收工
用首页“保存收工包 ZIP”，在浏览器下载列表确认保存，再用“核验已保存的收工包”选回。收工包包含三个工作区、实际媒体、已载入未接受的外部改稿、个人模板和相关文字。原协议不变，可返回原 R16.2 使用。

主影片工程、外部剪辑工程、未绑定文件、未应用能力档或组合预览、临时撤回点和播放器位置仍不在收工包里；主工程目录需要另行备份。

## 可选本机续作
已有 **Python 3.11+** 的 Windows 设备，双击 `OPEN_CONTINUE_WINDOWS.cmd`；其他系统运行 `python3 LOCAL_CONTINUE.py`。只用标准库，不安装第三方库。启动后主动开启“在本窗口开启自动续作”，或点“立即存一份恢复点”，才开始写入。默认不写。

恢复点在用户主目录 `ManjuRecovery`，独立于软件解压位置和浏览器缓存。重新启动服务后，查看、核验预览，再确认恢复。每窗口成功保存新点后保留自己最近三份，不清理其他窗口。默认上限 2 GiB、64 份；没有足够空间时先暂停，不先删旧点。

停笔约 8 秒后尝试保存，相邻自动保存至少间隔 30 秒；关窗瞬间不承诺保存。这个版本给**完整响应正文**加上超时约束，卡住会释放操作状态而不是永远显示处理中。超时只表示客户端没确认，不证明服务器一定没写入；重新查看恢复点后决定下一步，不要关闭还有未保存文字的页面。

本机恢复点不是独立备份，不能防硬盘故障或机器丢失。只有最近成功写入的现场能恢复；保存期间继续写的文字不被标成已保存。必要时“另存收工 ZIP”，并放到第二个安全位置。

## 完整影片应用与限制
完整包的 `APP/INSTALL_WINDOWS.cmd` 需要已有 Python，明确输入 INSTALL 才创建私有环境；成功后使用 `APP/START_WINDOWS.cmd`。影片渲染另需 FFmpeg／FFprobe 及项目依赖。上手小包不含影片应用安装包和源码历史。

本机服务仅绑定环回地址，固定路由与令牌，不作为公网或多人共享服务；恢复文件不加密、不含身份签名。直接 HTML 受限时，已有 Python 可用 `OPEN_LOCAL_WINDOWS.cmd` 只读备用入口。Windows 实机双击、安装与退出尚未验收，隔离浏览器演练不等于原生 Windows 端到端验收。

本版本基于真实可恢复的 r16.2，保持十二个能力档和质量名单，不冒充以前失去的原版 R17；没有商业生成调用、自动降档、云上传、选片或锁片。
